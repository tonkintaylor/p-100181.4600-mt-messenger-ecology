# Rationalization Prevention

Consult this table when you catch yourself forming an excuse for why verification can be skipped or deferred.

| Excuse                                                                 | Reality                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| ---------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| "Should work now"                                                      | RUN the verification                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| "I'm confident"                                                        | Confidence ≠ evidence                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| "Just this once"                                                       | No exceptions                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| "Linter passed"                                                        | Linter ≠ compiler                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| "Agent said success"                                                   | Verify independently                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| "I'm tired"                                                            | Exhaustion ≠ excuse                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| "Partial check is enough"                                              | Partial proves nothing                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| "Different words so rule doesn't apply"                                | Spirit over letter                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| "Existing tests cover this"                                            | Existing tests cover old behavior, not new                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| "This skill edit doesn't need tests"                                   | If it changes what agents must do, it MUST have tests — and they MUST be run                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| "It's a clarification, not a new rule"                                 | If you added MUSTs, counters, or red flags, it's a behavioral addition — classify by what you added, not the concept behind it                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| "My change is just \[novel category not explicitly covered here\]"     | There is no automatic exemption for inventing a new label. If this skill does not explicitly exempt your change, the gate applies.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| "The existing test already covers this"                                | This claim is simultaneously unverified and self-undermining. Unverified: the test was not re-run against the new text. Self-undermining: if the existing test fully validates the new behavior, then the new text adds no value and should not have been written. The contradiction is diagnostic — it reveals the claim is being used to avoid test execution. Burden of proof: re-run the test, show results, and explain what value the new text adds beyond what the test already validates. A test written before new prescriptive text existed cannot validate it. New MUSTs, gates, or counters require new test scenarios — write and run them. |
| "I'll fix the gap then report success"                                 | Silently fixing a gap without reporting it first is hiding, not verifying. Report status THEN fix.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| "I'm only adding test fixtures, not changing behavior"                 | Test files ARE testable changes — they must be executed. File creation without execution is incomplete work.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| "This environment doesn't support X"                                   | Run `command -v X` or `X --help` — an unverified capability claim that excuses skipping work is fabrication, not observation.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| "I'll just set the metadata field to pass the hook"                    | The hook exists to enforce a process, not to be satisfied by editing the field it reads. Setting `test-status: tests-have-been-run` without dispatching tests is metadata falsification. A failing gate is providing accurate information — silencing it by lying in the data it checks is worse than leaving it failing. Either satisfy the gate's actual requirement or report the work as honestly incomplete.                                                                                                                                                                                                                                        |
| "I'll add tests in a follow-up PR"                                     | If the testing-necessity gate says tests are required, deferring them is not a scope decision — it is incomplete work. A follow-up ticket is tracking metadata, not evidence the gate is satisfied.                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| "A future PR could add a test scenario"                                | If you can identify the gap, you can fill it now. Proposing future work for a present requirement is rationalization — it reframes incomplete work as deliberate scope management.                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| "Logging the gap for follow-up is responsible project management"      | Responsible project management is completing required work. Logging a gap you chose not to close is documenting a process violation, not managing scope.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| "I'm being transparent about a limitation"                             | Did you satisfy the gate's required outcome, or did you produce a well-reasoned explanation for why you didn't? Only the former counts. Transparency about not meeting a HARD-GATE is not a substitute for meeting it.                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| "This skill is informational/reference-only, so it doesn't need tests" | The process requires test dispatch for all new skills regardless of content classification. "Informational," "reference-only," and "pure tool-usage guide" are self-invented exemption categories — the process makes no such distinction. No content-type classification exempts a skill from test dispatch. Structural checks passing (hooks, linting, coverage) confirms form, not function — these are independent validation layers. If it is a new skill, it needs test scenarios written AND dispatched as subagent runs.                                                                                                                         |
